# update_rosdep
Shell to init and update rosdep offline  
`cd update_rosdep`  
`./rosdep_init_update.sh`  
Current branch is for ros noetic, ros2 humble, ros2 iron and ros2 jazzy. If you are using kinetic or melodic, please switch to kinetic or melodic branch.  
`git checkout kinetic --` or `git checkout melodic --`
